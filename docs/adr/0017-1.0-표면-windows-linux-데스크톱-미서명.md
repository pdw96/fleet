## 맥락

`fleet-advisor` 1차 심층 진단(후보 29건 → 확정 10·부분확정 16·전면기각 3)에서 **1.0 의 제품 표면이
정의된 적이 없다**는 것이 1번 안건으로 올라왔다. 릴리스는 `v0.1.0`(2026-06-21) 단건이고 그 이후
79건이 머지됐지만 도달한 사용자는 0이다. 표면이 미정인 채로는 「무엇이 부족한가」를 판정할 기준선이
없어 출시 부채 목록 자체가 만들어지지 않는다.

세 후보가 있었다: (a) 데스크톱 전용, (b) 데스크톱 + macOS, (c) 데스크톱 + 셀프호스트 서버.

동시에 **코드서명 지출 여부**가 첫 사용자 경험을 크게 가른다. 미서명이면 Windows SmartScreen 이
전체화면으로 차단하고(기본 버튼이 "실행 안 함") Linux AppImage 는 `chmod +x` 를 사용자가 해야 한다.

## 결정

**1.0 = Windows / Linux 데스크톱 앱 전용, 미서명.** macOS 출하와 셀프호스트 서버 편입은 post-1.0.
지출은 0으로 두고, 경고 우회 절차 문서화를 서명의 대체 완화책으로 **필수 출시 항목**에 넣는다.

데스크톱 전용이 이미 사실상의 상태라는 것이 결정 근거다 — 새로 좁히는 게 아니라 **암묵 상태를
문면화**하는 것이다:

- `electron-builder.yml:7` `- '!out/server/**'` 가 서버 번들을 asar 에서 이미 제외한다
- `README.md` 는 server·셀프호스트·`deploy/` 를 한 번도 언급하지 않는다
- `SECURITY.md:3,52` 의 위협모델이 이미 데스크톱 단독 전제로 쓰여 있다(배포 아티팩트 기준으로 참)
- 빌드 매트릭스 `release.yml:62` 가 `[windows-latest, ubuntu-latest]` 이고 `electron-builder.yml` 에
  `mac:` 블록이 없으며 `CSC_*`/`APPLE_ID` 가 레포에 없다

## 고려한 대안 / 기각 사유

- **macOS 포함**: dmg/zip 타깃·notarize 시크릿·darwin 가드 해제·`latest-mac.yml` 검증이 필요하고
  Apple Developer($99/yr)와 맥 하드웨어가 전제다. 8~16 사람-시간에 W4 가 1~2주 늘어난다. 사용자 0인
  단계에서 플랫폼을 넓히는 것보다 **한 플랫폼에서 첫 사용자를 만나는 것**이 선행. → 기각(post-1.0).
- **셀프호스트 서버 포함**: GHCR 공개 + 태그 연동 발행, Access 없는 로컬/LAN 모드, 멀티아치 buildx,
  `SECURITY.md` 위협모델 신설, 서버용 업그레이드·롤백 노트 = 12~20 사람-시간. 게다가 표면이 두 배가
  되면 출시 기준도 두 배다. **제외 명시 비용은 `SECURITY.md` 2~3줄**로 비대칭이 크다. → 기각(post-1.0).
- **서버 코드 제거**: 테스트 26파일 폐기 + 재도입 비용. 배포 표면에서만 빠지면 충분하고 그건 이미
  집행 중이다. → 기각(유해).
- **EV 코드서명 구매(~$300~400/yr)**: SmartScreen 즉시 통과라는 효과는 크지만, 사용자 0·수익 0
  단계의 연간 고정비다. 안내 문서로 부분 완화되며, 이탈이 실측되면 그때 사는 것이 순서. → 보류.

## 결과 (Consequences)

- **얻는 것**: 출시 기준선이 하나로 고정돼 부채 목록(#293 하위 13건)이 확정됐다. W4 범위가 닫힌다.
- **감수하는 비용**: ① mac 사용자는 받을 것이 없다 — README 에 **지원 OS 를 명시**해 「왜 없지」를
  없앤다. ② 미서명 경고가 첫 사용자 경험의 기본값으로 남는다 — 완화는 문서뿐이고 제거는 못 한다.
- **필수 후속(이 결정이 만든 의무)**: `SECURITY.md:3,52` 에 「배포되는 데스크톱 릴리스 아티팩트
  대상」 범위 한정 + 「`deploy/` 는 1.0 표면 밖」 1줄 · README 설치 절과 OS별 경고 우회 절차 ·
  릴리스 노트 고정 푸터(`--notes-file` 전환 필요 — 현재 `--generate-notes` 라 자리가 없다). = #304.
- **재검토 트리거**: ① 「SmartScreen 때문에 설치를 포기했다」는 사용자 보고 1건, 또는 다운로드 대비
  실행 이탈 관측 → EV 인증서 재론. ② mac 사용자 요청이 누적되거나 맥 하드웨어가 확보되면 → macOS
  레그 재론. ③ README/릴리스 노트에 셀프호스트를 사용자 대면 기능으로 광고하기로 하거나 GHCR
  패키지를 public 으로 전환하면 → `SECURITY.md` 에 서버 위협모델 절 신설이 **선행 조건**이 된다.
